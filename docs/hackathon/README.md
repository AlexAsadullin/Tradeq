# Материалы для хакатона T-Bank

Tradeq это платформа проверки торговых стратегий на Мосбирже, которая отделяет реальную доходность от
переобучения, подглядывания в будущее и идеального исполнения, и делает это одинаково для человека, робота и
агента на базе языковой модели.
